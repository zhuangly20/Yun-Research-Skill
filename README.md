# Research Skills



山野的云创建，清华大学心理学系博士生

分享适合中国大学生的中文版的科研 AI Skills 合集，不定期添加新的实用skill和新的版本迭代

每个 skill 可独立使用，也可以组合使用：用 arxiv-daily-report 抓前沿预印本，用 journal-daily-report 追踪正式期刊，用 paper-interpreter 精讲单篇论文。



## Skills



| Skill | 用途 | 数据源 | 链接 |

|-------|------|--------|------|

| arxiv-daily-report | 抓取 arXiv 预印本前沿论文，生成中文日报或针对具体问题做学术调研 | arXiv API | [查看](./arxiv-daily-report) |

| journal-daily-report | 追踪正式学术期刊（Nature、Science、NEJM 等 200+ 期刊）最新发表文章，生成期刊日报或领域扫描报告 | PubMed / OpenAlex / Crossref / Semantic Scholar | [查看](./journal-daily-report) |

| paper-interpreter | 上传单篇论文 PDF，按三步阅读法逐图逐表深度拆解，生成通俗版中文精讲报告 | 用户提供的论文 PDF | [查看](./paper-interpreter) |



## 如何使用



每个 skill 目录下有 `SKILL.md`（主 prompt）和 `使用指南.md`（操作说明）。

将对应的 skill 文件夹加载到 AI 编程工具（如 Trae、AutoClaw）中即可使用，三个 skill 互不冲突，可按需加载一个或全部加载。
