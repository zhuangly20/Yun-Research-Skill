# 学术论文精讲拆解器

上传一篇论文 PDF，得到一份结构化的中文精讲报告：基本信息、1 分钟速览、逐图逐表的核心逻辑拆解、延伸阅读推荐。

## 功能

- **单篇精讲**：把一篇论文从「为什么做」到「怎么做」到「发现了什么」完整拆给你看
- **逐图逐表拆解**：方法与结果部分紧贴原文图表，有图必讲、有表必解
- **知识网络拓展**：解释论文依赖的核心理论，并从参考文献中精选 2-3 篇基石文献推荐

## 方法论：Keshav 三步阅读法

本 skill 的拆解逻辑源自 Keshav 教授 2007 年的经典论文 **How to Read a Paper**（ACM SIGCOMM CCR），将读论文分为三遍，层层深入：

| 步骤 | 目标 | 读什么 |
|------|------|--------|
| 第一遍 | 快速判断是否值得读 | 标题、摘要、引言、小结 |
| 第二遍 | 抓住论文的主要内容和贡献 | 全文（跳过证明细节） |
| 第三遍 | 深入理解细节，批判性思考 | 逐段精读，复现关键内容 |

## 报告结构

每份解读报告按四大部分输出：

1. **📁 文章基本信息**：标题、期刊与影响因子、DOI、第一/通讯作者
2. **💡 研究概览**：200-300 字讲清楚来龙去脉，1 分钟把握全文
3. **🔬 文章精讲**：Why（问题提出）/ What（研究内容）/ How（逐图逐表拆解）/ So What（结论）/ 局限与未来方向
4. **📚 推荐学习**：核心理论释义 + 基石文献推荐

写作上遵循费曼学习法：通俗但不轻佻，精确数值与因果链条一个不少，原文没说的直接标注「本研究未提及」，绝不捏造。

## 三个 skill 怎么配合

| 特性 | arXiv 日报 | 期刊日报 | 论文精讲 |
|------|-----------|---------|---------|
| 解决的问题 | 领域里最新出了什么预印本 | 顶刊这一期发了什么 | 这篇论文到底讲了什么 |
| 输入 | arXiv 分类/关键词 | 期刊目录/主题 | 一篇论文 PDF |
| 输出 | 每日论文清单与速览 | 期刊目录与领域扫描 | 单篇深度精讲报告 |
| 典型用法 | 每天刷前沿 | 每周追顶刊 | 精读绕不开的关键文献 |

三个 skill 互不依赖，可单独使用；也可以先用日报筛出值得读的论文，再用本 skill 精讲。
