# 使用指南

## 快速开始

### 1. 导入 Skill

将 `SKILL.md` 和 `期刊目录.md` 导入你使用的 AI 平台。

**AutoClaw：**
1. 打开 AutoClaw
2. 点击「添加 Skill」
3. 选择 `SKILL.md` 文件
4. 将 `期刊目录.md` 放在同目录下

**Claude Code：**
```bash
# 方式一：全局 skill
cp SKILL.md ~/.claude/skills/journal-daily-report.md
cp 期刊目录.md ~/.claude/skills/期刊目录.md

# 方式二：项目级 skill
cp SKILL.md .claude/skills/journal-daily-report.md
cp 期刊目录.md .claude/skills/期刊目录.md
```

**Trae：**
1. 打开 Trae
2. 在对话中直接粘贴 `SKILL.md` 的内容
3. 或保存为项目文件


## 常见问题

### Q: 数据源 API 有使用限制吗？

| 数据源 | 限制 |
|--------|------|
| OpenAlex | 100,000 次/天（免费） |
| PubMed | 无 API key: 3次/秒；有 key: 10次/秒 |
| Crossref | 无硬限制，建议加 mailto 参数 |
| Semantic Scholar | 100 次/5分钟 |

日常使用不会触发限制。如遇到限流，skill 会自动切换备用数据源。

### Q: 如何获取 PubMed API key？

1. 访问 https://www.ncbi.nlm.nih.gov/account/
2. 注册/登录账号
3. 在 Settings 中生成 API Key
4. 使用时提供给 skill 即可

### Q: 中文期刊支持吗？

支持，但需要注意：
- 中文期刊在 OpenAlex 和 Crossref 中的覆盖可能不完整
- 建议结合 CNKI（知网）数据库使用
- 预置了部分 CSSCI 核心期刊，可自行添加

### Q: 影响因子数据准确吗？

本 skill 使用 OpenAlex 的 **2-year mean citedness** 作为影响因子的近似指标：
- 计算方式：该刊过去2年发表论文的平均被引次数
- 与 Clarivate 官方 JCR 影响因子可能有差异
- 仅供参考，用于比较期刊间相对影响力

### Q: 可以追踪预印本吗？

本 skill 专注于正式发表的期刊文章。如需追踪预印本：
- 使用作者的另一个 skill：[arXiv 日报生成器](../arxiv-daily-report/)
- arXiv 有免费 API，适合追踪最新预印本

## 进阶用法

### 组合使用多个数据源

如果某个数据源没有你想要的期刊，可以手动指定：

```
"用 PubMed 查 NEJM 最新一期"
"用 Semantic Scholar 查 IEEE TPAMI 的文章"
```

### 自定义时间范围

```
"Nature 最近 3 天的文章"
"心理学期刊最近一周有什么"
"JPSP 2024 年的文章"
```

### 限定文章类型

```
"NEJM 最近的综述文章"
"Nature 最近的研究论文（不要评论和新闻）"
```

### 导出格式

报告默认保存为 Markdown 文件，你也可以要求其他格式：

```
"把报告保存为 PDF"
"生成 HTML 版本"
```
